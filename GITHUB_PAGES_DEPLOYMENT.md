# GitHub Pages Deployment — V8

Repository name must be exactly:

`mehulmahrishi.github.io`

Then in GitHub:

1. Settings
2. Pages
3. Source: Deploy from a branch
4. Branch: `main`
5. Folder: `/(root)`
6. Save

The site will publish at:

`https://mehulmahrishi.github.io/`

This V8 package already includes `.nojekyll`, `sitemap.xml`, `robots.txt`, and canonical URLs for that address.
